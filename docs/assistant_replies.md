# Шаблоны ответов ассистента

## Общие правила

-   Использовать женский род: «записала», «не расслышала», «нашла».
-   Обращаться к пользователю на «ты».
-   Один факт на предложение.
-   Не использовать восклицания и извинения.
-   Даты показывать словами, если это естественно: «завтра», «пт, 23
    октября».
-   Время показывать в формате `15:00`.
-   Переменные обозначать в фигурных скобках, например `{title}`.
-   Сообщения об успешном действии показывать только после подтверждения
    от backend.
-   Если действие не выполнено, не использовать формулировки, которые
    утверждают обратное.

## Создание

  -----------------------------------------------------------------------
  Ситуация                            Текст
  ----------------------------------- -----------------------------------
  Задача с датой                      Записала задачу: «{title}» ---
                                      {date}.

  Задача без даты                     Записала задачу: «{title}».

  Встреча                             Записала встречу: «{title}» ---
                                      {date}, {time}.

  Напоминание                         Напомню: «{title}» --- {date},
                                      {time}.

  Конфликт встреч                     На это время уже запланирована
                                      встреча «{title}». Выбери другое
                                      время.
  -----------------------------------------------------------------------

## Уточнения

  Чего не хватает          Текст
  ------------------------ ----------------------------------------------
  Время                    На какое время поставить «{title}»?
  Дата                     На какой день поставить «{title}»?
  Дата и время             На когда поставить «{title}»?
  Название                 Что записать?
  Время непонятно          Не поняла время. Скажи, например: «в 15:00».
  Подсказка под вопросом   Назови время голосом или выбери вариант.
  Отмена                   Хорошо, отменила.

## Список записей

  Ситуация                       Текст
  ------------------------------ ---------------------------
  Заголовок списка               {period}: {count_label}
  Скрыты дополнительные записи   И ещё {remaining_count}.
  Пустой день                    На сегодня ничего нет.
  Нет встреч                     Встреч на завтра нет.
  Нет задач                      Задач на этой неделе нет.

### Правило склонения слова «запись»

Форму слова выбирает frontend по числу:

-   `1 запись`
-   `2–4 записи`
-   `5–20 записей`
-   `21 запись`
-   `22–24 записи`
-   `25–30 записей`

Для чисел больше 20 правило повторяется по последним двум цифрам, кроме
чисел, оканчивающихся на 11--14: для них используется «записей». Для
значения `0` используется «записей».

В `{count_label}` передаётся уже сформированная строка с числом и
правильной формой слова, например `5 записей`.

## Поиск

  Ситуация                    Текст
  --------------------------- --------------------------------------------------
  Одна запись найдена         Нашла одну подходящую запись.
  Несколько записей найдены   Нашла {count_label}. Вот самые близкие.
  Ничего не найдено           Ничего похожего не нашла. Попробуй другие слова.

В `{count_label}` передаётся количество с корректным склонением,
например `3 записи` или `5 записей`.

## Изменение записей

Дополнительные сценарии: использовать эти ответы только если
соответствующие действия реализованы backend.

  Действие    Текст
  ----------- -----------------------------------------
  Перенос     Перенесла «{title}» --- {date}, {time}.
  Удаление    Удалила «{title}».
  Выполнено   Отметила как выполненное: «{title}».

## Ошибки и особые состояния

  -----------------------------------------------------------------------
  Код / ситуация                      Поведение или текст для
                                      пользователя
  ----------------------------------- -----------------------------------
  `EMPTY_INPUT`                       Скажи или напиши, что нужно
                                      сделать.

  `STT_FAILED`                        Не расслышала. Нажми на микрофон и
                                      повтори или напиши текстом.

  `TTS_FAILED`                        Не показывать сообщение об ошибке.
                                      Если текстовый ответ получен,
                                      оставить его на экране; голосовое
                                      воспроизведение недоступно.

  `MISSING_SESSION`                   Что-то пошло не так. Обнови
                                      страницу.

  Сервис недоступен или таймаут       Сервис сейчас недоступен. Попробуй
                                      через минуту.

  `MEETING_CONFLICT`                  На это время уже запланирована
                                      встреча «{title}». Выбери другое
                                      время.
  -----------------------------------------------------------------------

## Подписи интерфейса

  Место             Текст
  ----------------- -----------------------------------------
  Idle, заголовок   Скажи, что записать или найти
  Idle, подпись     Нажми на микрофон или напиши. Например:
  Поле ввода        Скажи или напиши
  Запись            Слушаю... Нажми, чтобы закончить
  Поле при записи   Идёт запись
  Обработка         Обрабатываю...
  Кнопки            Отменить, Повторить, Показать всё

## Примечания для реализации

-   `MEETING_CONFLICT` показывать только если backend вернул
    соответствующий код. Не подтверждать создание конфликтующей встречи.
-   При `TTS_FAILED` сохранять текстовый ответ и не показывать отдельную
    ошибку пользователю.
-   Для числительных использовать отдельную функцию склонения, а не
    вставлять несколько форм слова через `/`.
-   Не показывать подтверждение создания, переноса или удаления до
    успешного ответа backend.
