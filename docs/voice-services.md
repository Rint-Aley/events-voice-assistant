# Карта документов

Точка входа в техническую документацию по голосовым сервисам.

## Файлы

| Файл | Описание |
|---|---|
| `stt.md` | Спецификация сервиса распознавания речи (Whisper) |
| `tts.md` | Спецификация сервиса синтеза речи (edge-tts + S3) |
| `../architecture.md` | Общая архитектура системы и потоков данных |
| `../contracts/` | HTTP-контракты и JSON-схемы обмена |

## Порядок чтения
1. `../architecture.md` - для понимания общей картины и места сервисов в системе.
2. `../contracts/` - для понимания форматов обмена (запросы, ответы, коды ошибок).
3. `stt.md` и `tts.md` - для деталей реализации, конфигурации и внутренних механизмов.
