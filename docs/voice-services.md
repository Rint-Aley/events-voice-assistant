# Карта документов

Точка входа в техническую документацию проекта.

## Файлы

| Файл | Описание |
|---|---|
| `stt.md` | Спецификация сервиса распознавания речи (Whisper) |
| `tts.md` | Спецификация сервиса синтеза речи (edge-tts + S3) |

| `../contracts/` | HTTP-контракты и JSON-схемы обмена |

## Порядок чтения
1. `../architecture.md` - для понимания общей картины.
2. `../contracts/` - для понимания форматов обмена.
3. `stt.md` и `tts.md` - для деталей реализации голосовых сервисов.
