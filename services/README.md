# Voice Services (STT & TTS)

Два HTTP-сервиса для голосового ассистента. Реализация полностью соответствует контрактам `docs/contracts/stt.*.json` и `docs/contracts/tts.*.json`.

## Стек
- **STT:** faster-whisper (модель `base`, CPU). Требует ffmpeg.
- **TTS:** edge-tts (голос `ru-RU-SvetlanaNeural`). Требует ffmpeg.
- **Хранилище:** TTS загружает аудиофайлы в S3 (RustFS).

## Запуск
Все сервисы (включая базу данных и S3) поднимаются одной командой из корня проекта:
```bash
docker compose up -d --build
```

## Эндпоинты

**POST /v1/transcribe (порт 8010)** - аудио по `audio_url` -> текст:
- `audio_url` принимает только http/https (presigned-ссылки S3).
- Возвращает распознанный текст, уверенность (avg_logprob) и длительность.
- Коды ошибок: 400 (схема), 413 (PAYLOAD_TOO_LARGE), 422 (AUDIO_TOO_LONG, AUDIO_UNREADABLE), 503, 504.

**POST /v1/synthesize (порт 8020)** - текст -> аудио:
- Синтезирует текст, конвертирует и загружает в S3.
- Возвращает `object_key` (путь в бакете `tts`).
- Ключ кэша детерминирован: `sha256(text + voice + format + speed)`.
- Повторный запрос возвращает `cached: true`.

## Особенности реализации
- **Валидация:** строгая Pydantic-валидация (`extra="forbid"`), жесткая проверка типов.
- **Таймауты:** STT - 25 с. TTS - 20 с (включая синтез и конвертацию).
- **Антигаллюцинации:** в STT включен `vad_filter=True` для отсечения тишины.
- **S3:** TTS проверяет наличие файлов через `head_object` и кэширует длительность в метаданных.
